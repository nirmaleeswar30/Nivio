Android TV

Nivio runs on Android TV and Google TV devices, such as the Chromecast with Google TV, NVIDIA Shield and Android-based smart TVs, with a layout built for the big screen and your remote.

Install it

Nivio isn't in the Play Store, so you sideload the same nivio.apk used on phones. The easiest way is the free Downloader app:

  1. On your TV, install Downloader from the Play Store.
  2. Allow it to install apps: Settings → Apps → Security & restrictions → Unknown sources (the menu names vary by device).
  3. In Downloader, enter https://github.com/nirmaleeswar30/Nivio/releases/latest, download nivio.apk and install it. Older 32-bit boxes need universal.apk instead.

If you use a computer, adb install nivio.apk works too. Nivio recognises the TV on first launch and switches to the TV layout by itself.

The TV layout

On a TV, Nivio uses its big-screen layout: a navigation rail down the side, poster grids, and wide detail pages. Everything is reachable with the D-pad, and the focused item is clearly highlighted.

HDR and Dolby Vision on TV

A TV box reports what your TV supports, so Nivio can play true HDR and, where the box has a Dolby Vision decoder, Dolby Vision. The HDR settings work the same as on phones. See HDR & Dolby Vision.

Ambient mode is a phone feature and doesn't appear on TV.

Updating

Nivio shows an Update available prompt when a new version is out. Install the new APK over the old one the same way; your data stays.
