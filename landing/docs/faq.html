Troubleshooting & FAQ

Quick fixes for the problems people run into most. If yours isn't here, report it.

A video won't load or keeps buffering

  • Try another server. Tap the circular arrows at the top right of the player and pick a different server card. Sources go down and come back often.
  • Give fallback a moment. When a source fails, Nivio tries the next one by itself, which can take a few seconds.
  • Check your connection or DNS. Some networks and ISPs block streaming sites. Setting a DNS over HTTPS URL under Settings → Network often helps.
  • Torrents stall? Pick a result with more seeders. See Torrent streaming.

Sound plays but the screen is black or green

This is almost always a decoding problem. Open the player settings, tap Decoder and switch to HW, or SW if that doesn't help. On an HDR video, try the other HDR Surface Output in the HDR tile. See Decoder modes.

HDR looks washed out, too dark, or the colours are off

See HDR troubleshooting. Short version: check what the HDR tile says, switch the surface output, or turn HDR Output off to tone-map instead.

Subtitles are missing or out of sync

  • Pick a different subtitle track under Subtitles, or load your own .srt / .vtt file or URL there.
  • Use Subtitle sync to shift them earlier or later.
  • Set your default language in Settings → Preferred Subtitle Language.

Updating doesn't work on Windows or Linux

Since the version after 2.2.5, tapping Install on the update prompt downloads the update, installs it and restarts Nivio for you. On 2.2.5 or older:

  • Windows: close Nivio completely, then run the new Nivio-Setup. It upgrades the existing install; there's no need to uninstall first. If Nivio seems to be closed but the installer still says files are in use, end nivio.exe in Task Manager.
  • Linux: replace the old AppImage with the new one, keeping the same file name so your shortcuts still work.

See Install & update for details.

Windows says it protected my PC

That's SmartScreen warning about an app that isn't code-signed. Click More info → Run anyway. Only download Nivio from GitHub Releases or this site.

The Linux AppImage won't start

Make sure it's executable (chmod +x), and install FUSE 2: libfuse2 on Debian and Ubuntu, fuse2 on Arch and Fedora. If you sign in to AniList, MyAnimeList, Simkl or Google and the browser doesn't return to Nivio, open Nivio once from the AppImage so it can register its nivio:// link handler.

The screen turns off while I'm watching

Nivio keeps the screen on while a video plays, including in the mini player and while downloads run. If it still sleeps, update to the latest version; older versions could lose the screen-on hold when moving to the next episode.

Will I lose my history or settings?

Not when you update. On Android, uninstalling deletes your local data, so sign in with Google first if you want your watchlist and history back afterwards. Clearing the cache in Settings only removes cached posters and metadata.

Is Nivio on the Play Store?

No. Nivio is only distributed through GitHub Releases (and Obtainium, which installs from GitHub). Copies on other sites aren't ours and may be modified.

Is it really free?

Yes. Nivio is free and open source under the MIT License, with no ads and no subscriptions. If you'd like to support development, you can sponsor it on GitHub.

Report a bug or request a feature

Open an issue on GitHub. To help us fix it fast, include:

  • Your device and platform (for example, Pixel 8 on Android 15, or Windows 11)
  • Your Nivio version (Settings → App & Updates → App Version)
  • What you were playing, which server, and what happened
  • A screenshot, or the Stats for nerds overlay for playback problems

Something wrong or missing? Open an issue on GitHub.
