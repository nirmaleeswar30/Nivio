Getting started

Install & update

Nivio is distributed only through GitHub Releases. It isn't on the Play Store, and builds from other sites aren't ours.

Android

AndroidPhones & tablets

Each release has two Android files. Pick one:

FileUse it when
nivio.apkYour phone is from the last several years (64-bit ARM). Smaller download. This is the right one for almost everybody.
universal.apkYou have an older 32-bit phone, an x86 device or an emulator, or nivio.apk won't install.
  1. Open the latest release on your phone and download the APK.
  2. Open the downloaded file. If Android asks, allow your browser or file manager to install unknown apps.
  3. Tap Install, then open Nivio.
Tip

Use Obtainium to get new versions automatically, straight from GitHub.

Updating on Android

Nivio gets updates in two ways:

  • Small fixes arrive over the air in the background. The next time you open Nivio, you're on the fixed version.
  • New versions show an Update available prompt with the release notes. Tap Install to download the new APK, then install it over the current one. Your library, history and settings stay.

You can also check by hand in Settings → App & Updates → Check GitHub Release.

Android TV

The same nivio.apk runs on Android TV and Google TV. Nivio detects the TV and switches to its TV layout. See Android TV for how to sideload it.

Windows

Windows 10 & 1164-bit
  1. Download Nivio-Setup-<version>.exe from the latest release.
  2. Run it. If Windows SmartScreen says it protected your PC, click More info → Run anyway. Nivio is open source but not code-signed, which is why SmartScreen warns about it.
  3. Follow the installer. Nivio installs to Program Files\Nivio and adds a Start menu entry.

Trailers and previews use Microsoft Edge WebView2, which comes with Windows 10 and 11. On minimal or LTSC editions, install the WebView2 Runtime first.

Updating on Windows

When a new version is out, Nivio shows an Update available prompt. Tap Install and Nivio downloads the update, closes, installs it over the old version and opens again. Windows may ask for permission once, because Nivio lives in Program Files.

Note

You never need to uninstall Nivio to update it. Running a newer Nivio-Setup over an existing install upgrades it in place, keeping your data. The installer closes Nivio first if it's still running.

The automatic install arrived after version 2.2.5. On 2.2.5 and older, Install opens the download in your browser. Close Nivio completely before you run the downloaded setup.

Linux

x86_64AppImage
  1. Download Nivio-Linux-<version>-x86_64.AppImage from the latest release, ideally into a folder you keep, such as ~/Applications.
  2. Make it executable, then run it: 
    chmod +x Nivio-Linux-*-x86_64.AppImage
./Nivio-Linux-*-x86_64.AppImage
  3. On first run, Nivio registers itself to open nivio:// links, which sign-in with AniList, MyAnimeList, Simkl and Google relies on.

The AppImage bundles mpv, so there's nothing else to install. If it doesn't start, your system may be missing FUSE 2: install libfuse2 (Debian, Ubuntu) or fuse2 (Arch, Fedora).

Updating on Linux

Tap Install on the Update available prompt. Nivio downloads the new AppImage, swaps it in under the same file name and restarts. Your launcher shortcuts and the nivio:// link handler keep working, because the file stays where it was.

Updating by hand works too: replace the old AppImage file with the new one, and keep the same name if you have shortcuts pointing at it.

Where your data lives

Updating never touches your library, history or settings. Uninstalling on Android deletes them along with the app. If you sign in with Google, your watch history and watchlist also sync to the cloud and come back when you sign in again. See Sync & integrations.
