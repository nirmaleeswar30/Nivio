Together

Watch Party

Watch together with friends on any mix of phones, TVs and computers. Play, pause and seeking stay in sync for everyone in the room.

Start a party

  1. Open a movie or show and tap the people icon, or go to the Watch Party tab and pick a title there.
  2. Tap Start Watch Party. You're the host.
  3. Tap Share Link to send an invite through any app. It includes a room code and a link that opens Nivio straight into the party.

Join a party

Open the invite link from a friend, or go to the Watch Party tab, type the room code into Join with code and tap Join Party. Nivio opens the same title and jumps to where the host is.

Tip

Everyone needs Nivio installed to join. Send the install page along with your invite.

Who controls playback

The host controls playback for everyone by default. The host can hand control to one other person from the party panel, and keeps control too. Tap Host Controls to take it back. A game-controller icon marks whoever currently has control.

Chat

A chat overlay in the player lets everyone talk without leaving the video. It appears with the controls and stays out of the way while you watch.

Leave

Tap Leave Party in the party panel. When the host ends the party, it ends for everyone and each person sees a message saying so.

On Android, a party stays connected in the background for a while, so switching apps for a moment doesn't drop you.
