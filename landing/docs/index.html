Nivio Docs

Everything Nivio can do, and how to use it

Nivio is a free, open-source app for Movies, TV Shows, Anime and Live TV, with Watch Parties and offline downloads. It runs on Android phones, Android TV, Windows and Linux. These pages explain how to set it up and get the most out of it.

Note

Nivio doesn't host any media. It finds metadata and streams from third-party sources on the internet. You're responsible for following your local laws when you use it. Official downloads are only on GitHub and this site.

Features at a glance

AnimeSeveral sources with automatic fallback, sub or dub, filler tags and skip intro. Torrent streamingPlay torrents while they download, with the built-in Rust engine. Live TV & IPTVLive channels, sports, and your own M3U or Xtream playlists. Watch PartyWatch in sync with friends, with shared controls and chat. DownloadsSave movies and episodes to watch offline. Android TVA full TV layout you drive with the remote. Sync & integrationsCloud sync, AniList, MyAnimeList, Simkl and Discord.
